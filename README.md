# Juraj Belohorec — personal website

This folder is ready to publish with GitHub Pages.

## Publish it

1. Sign in to GitHub and create a new **public** repository named `YOUR-USERNAME.github.io`, replacing `YOUR-USERNAME` with your exact GitHub username.
2. Open the new repository and choose **Add file → Upload files**.
3. Upload `index.html`, `profile.png`, and `.nojekyll` from this folder. You may upload this `README.md` as well.
4. Commit the uploaded files to the `main` branch.
5. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

After GitHub finishes publishing, the website will be available at:

`https://YOUR-USERNAME.github.io`

To update the website later, replace the relevant files in the repository and commit the changes. GitHub Pages will republish automatically.
